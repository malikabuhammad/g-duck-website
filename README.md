# G.Duck Jordan Website

A lightweight, playful, modern website for G.Duck Jordan built with Next.js, React, and CSS animations.

## Features

- 🎈 Smooth animations with Framer Motion + CSS keyframes
- 📱 Fully responsive and mobile-optimized
- ⚡ Fast loading with optimized images (WebP)
- 🎨 Playful, kid-friendly design
- 🦆 Interactive duck mascot (draggable, hover effects)
- ✨ Scroll-triggered animations
- 🎯 Hover and tap interactions throughout
- 🎪 Drag-and-drop duck icons

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Performance

- Optimized for Lighthouse scores (mobile)
- Lazy loading for images
- Framer Motion for smooth, performant animations
- CSS animations where appropriate
- Minimal bundle size impact
